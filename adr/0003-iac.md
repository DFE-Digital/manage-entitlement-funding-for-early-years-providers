# ADR-0003: Provision infrastructure using Infrastructure as Code

* Status: accepted

## Context and Problem Statement

The service will require multiple environments and must support repeatable deployment, recovery and change management.

Manual infrastructure creation introduces configuration drift and reduces reproducibility.

## Considered Options

* Infrastructure as Code using Terraform or Bicep
* Partially automated infrastructure
* Manually managed infrastructure

## Decision Outcome

All production infrastructure will be managed through Infrastructure as Code.

Terraform and Bicep are approved implementation technologies.

Manually-created infrastructure is not regarded as a supported operational model.
