# ADR-0002: Use .NET on Azure

* Status: accepted

## Context and Problem Statement

The service requires a technology platform that can be supported within DfE's existing cloud environment and aligns with departmental capability, hosting and operational practices.

## Considered Options

* .NET on Azure
* Alternative runtimes on Azure
* Alternative cloud providers

## Decision Outcome

The service will be implemented using .NET and hosted in Azure.

Alternative runtimes and hosting approaches are not being pursued because they would introduce additional operational and support complexity without a clear benefit for the service.
